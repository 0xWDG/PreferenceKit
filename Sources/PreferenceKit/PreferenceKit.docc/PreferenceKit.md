# ``PreferenceKit``

Build a consistent SwiftUI settings screen with support, legal, and developer
information.

## Overview

Use ``PreferenceKit`` as the contents of a settings screen. It supplies the
application header, App Store update and review links, changelog,
acknowledgements, a privacy policy, feedback, and developer profile links.

The package exposes only the view and the models needed to configure it:

- ``PreferenceKit``
- ``Acknowledgement``
- ``ChangeLogEntry``
- ``SocialMediaLink``
